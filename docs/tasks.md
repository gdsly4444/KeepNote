# KeepNote 开发任务

状态：草案 v0.1  
日期：2026-11-15  
依据：`docs/PRD.md`、`docs/coding-standards.md`、`docs/agent-architectures.md`

按模块顺序做。前一个模块的「完成」没达到，不开始下一个。每个任务只通过自己的模块入口和 `shared` 契约与别人协作。

已经定下、任务里不再重开的选择：

- 外壳是 Electron。长文、日记、工作记录和清单用 TipTap。技术笔记和源码模式用 CodeMirror 6。
- 界面在 `renderer`，库、命令、索引和 Agent 循环在 `main`，两边只经过 `shared`。
- Agent 循环自己写。模型流式协议用 `@earendil-works/pi-ai`。不嵌入 Pi 编码 Agent、Claude Code 或 Codex。
- 工作记录路径是 `work/年/月/日期.md`，日记路径是 `journal/年/月/日期.md`。
- 「今天改过」只看文件修改时间。清单归档先移到文末的「已完成」分组。

目录在模块 1 里一次建好：

```text
shared/          契约
main/
  platform/      路径、换行、退出
  vault/         库
  documents/     从 Markdown 读出类型和结构
  commands/      命令登记
  index/         索引
  agent/         循环与工具
  model/         pi-ai 客户端
  compose.ts     组合根
preload/
renderer/
  tokens/
  client/
  documents/     五种文档页，互相不引用
  command-bar/
  sidebar/
  shell/
```

## 模块 1 · 进程骨架

目标：窗口和主进程同生同灭，渲染进程碰不到磁盘。

| 任务 | 层 | 内容 | 完成 |
| --- | --- | --- | --- |
| 1.1 | 工程 | TypeScript 严格模式、Electron、Vite。四块目录和组合根就位 | `main` 能创建窗口，`renderer` 能显示一页空壳 |
| 1.2 | 契约 | 定义桥的类型：`run`、`query`、`subscribe`。先放一条 `ping` | 渲染进程只依赖这个类型 |
| 1.3 | 逻辑 | 单实例锁。再次启动只唤醒已有窗口。平台模块提供「最后一个窗口关闭时是否退出」 | Windows 和 Linux 关窗即退出。macOS 关窗后进程空闲，明确退出才结束 |
| 1.4 | 桥 | preload 实现契约，打开上下文隔离 | 渲染进程的业务代码不出现 `ipcRenderer` |
| 1.5 | 检查 | ESLint 禁止跨层引用，禁止层内绕过模块入口 | 故意写一条非法 import 时检查失败 |

## 模块 9 · Agent

目标：模型在云端推理，循环在主进程，改动先变成差异。

| 任务 | 层 | 内容 | 完成 |
| --- | --- | --- | --- |
| 9.1 | 逻辑 | 模型客户端包装 `pi-ai`。密钥只存在主进程 | 换提供者时循环和工具不改 |
| 9.2 | 逻辑 | 薄循环：流式文本、工具调用、取消信号。被截断的工具参数不执行 | 退出应用时进行中的请求被取消，未接受的差异不写盘 |
| 9.3 | 逻辑 | 工具只有：读一节、按索引检索、提出差异、新建文档、追加工作记录 | 工具里没有 shell，也不读库外文件 |
| 9.4 | 逻辑 | 第一轮上下文是用户的话、路径、类型、大纲和选区。正文按节读取。会话保存原始记录，超预算时在下一次请求前压缩，工具调用和结果不拆开 | 侧栏能列出这一轮实际读过的文件 |
| 9.5 | 契约 | 差异按工作记录的一条或一节、段落、日记条目、任务项、源码行组 | 三种入口进入同一次会话：命令行、侧栏、选区工具条 |
| 9.6 | 界面 | 差异画在对应文档页上。接受调用 `applyDiff`，放弃后正文回到原样，会话保留这次提议 | 同一句改写从三个入口得到同一份差异；接受或拒绝后文件内容正确 |
| 9.7 | 逻辑 | 模型结果必须能放进当前类型。类型不对时改为提议转换，转换本身到模块 10 才写入 | 清单不会收到一段无法对应到任务项的散文并直接落盘 |

## 完成的含义

模块 7 完成时，对照 PRD 的 P0 验收：启动进入今天；在技术笔记里 `log` 两次而不离开该页；把今天改过的长文收进产出；写下「在做」和「留下」；追加日记；勾选清单；五种页面能立刻分清。

模块 9 和 10 完成时，对照 P0 之后的 P1 验收：三个入口得到同一份差异，差异单位和类型一致，类型转换先有预览。

模块 11 完成时，全文检索和按库回答可用。
